## How the lessons work

- **Run code in the page.** Code blocks marked as runners can be edited and run in the browser. Python and Java runners call the kit's backend, so start the backend locally if a runner reports a network error.
- **Open the notebook.** Every lesson is a `.ipynb` file under `_notebooks/Lessons/`. Open it in VS Code or Jupyter to run the cells with a Python or Java kernel (see the [kernels guides]({{ site.baseurl }}/guides/)).
- **Practice.** Popcorn hacks are short in-lesson exercises; homework hacks are longer tasks to finish on your own.
